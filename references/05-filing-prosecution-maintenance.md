# 5. 提交申请、处理审查和维护专利

本文件指导准备和记录正式事务。以国知局官方系统和通知书为准，不要只凭技能中的日期或计算结果办事。

## 提交前要确认

1. 打开 references/06-authoritative-sources.md，查看现行提交要求和系统公告。
2. 确认申请类型、申请人/发明人、优先权、申请文件、附图和附件。
3. 将未知信息列入待办，不要猜填。
4. 请申请人或代理师确认最终文本、申请策略和请求书信息。
5. 由有权限的申请人或代理机构在国知局系统递交和缴费。
6. 保存提交回执、申请号、提交版本和缴费凭证。

技能不代替用户登录或操作系统。不要用本地文件时间推断申请日。

## 维护案件台账

每次收到官方通知或缴费事项，都记录：

- 通知书原件和下载日期
- 官方系统显示的送达/期限信息
- 事项、责任人和下一步
- 期限的起算事件和规则来源
- 核对人、核对日期和缴费凭证

每个期限都要写明来源并复核。日期不确定时标“待核实”，尽快交代理师确认。可用 templates/docket.md。

## 收到审查意见

先收齐通知书、当前申请文件、历次修改和通知书引用的对比文件。然后逐项整理：

1. 审查员指出了什么问题，原文在哪一页？
2. 涉及哪项权利要求、说明书或附图？
3. 引用了哪条规则、哪篇对比文件？
4. 对比文件实际公开了什么？原文位置在哪里？
5. 有哪些答复方案？每种方案会怎样影响保护范围？
6. 计划修改的内容在原始申请的什么位置有依据？

答复稿包括问题清单、逐项分析、修改稿、修改对照表和待确认事项。修改不得加入原始申请没有披露的内容。提交前由申请人或代理师确认并通过官方系统递交，之后保存回执。

不要保证一定授权。收到驳回决定时，先核实救济方式和期限，再交代理师处理。

## 授权后要记录

以官方通知和系统记录确认授权、登记手续、费用和证书。保存专利号、授权日、最终权利要求和缴费凭证。

随后记录年费年度、官方显示的应缴日、金额、减缴状态、负责人和提醒日期。费用和期限每次都从现行官方系统核对，不要沿用旧表格中的固定数字。
