# 检索与可专利性分析

用于申请前查新、已有申请的审查预判，以及根据对比文件调整技术披露。检索报告是工作底稿，不是官方查新结论，也不等于自由实施分析。

## 1. 形成检索问题

先将选定技术方案拆成：

- 技术领域和具体应用场景
- 技术问题
- 核心部件、数据、步骤和它们之间的关系
- 被认为产生技术效果的必要特征
- 同义术语、上位词、旧称、英文术语和分类线索

用若干组短语组合检索，不要只用完整标题或“系统/方法/平台”等宽泛词。按需要加入发明人、申请人、分类号、申请日或公开日限制。

## 2. 选择来源与记录

中国申请优先查国家知识产权局公布公告系统和专利审查信息官方入口。可用 Google Patents、WIPO PATENTSCOPE、学术数据库和出版商页面拓展线索；每件关键文献都回到可打开的原始专利/论文来源核实。

每条结果记录：数据库、确切查询式、查询日期、公开/申请号、标题、申请人/作者、优先权与公开日、同族关系、法律状态来源、相关段落/权利要求/附图，以及为何相关。不要把专利家族成员重复计作多个独立公开。

区分：

- 申请日、优先权日、公开日和当前法律状态；
- 在申请日前已公开的材料与之后公开的材料；
- 可用于专利性分析的公开文本与仅作背景的材料；
- 已核实记录与仅有摘要、搜索片段或二手引用的线索。

记录公开时间时须打开来源核对。不能确定的日期不得作为确定结论。

## 3. 建立逐特征对比

先选最接近的单篇现有技术作为主对比文件，再逐项比对权利要求或候选发明点。可用第二篇文献补充不同技术启示，但不得把多篇文献机械拼接后宣称单篇已公开全部特征。

| 对比维度 | 记录内容 |
|---|---|
| 本申请特征 | 来自交底或源材料的原子化技术限定 |
| 对比文件位置 | 权利要求、说明书段落、附图及原文定位 |
| 相同/不同/未记载 | 仅按所核实文本判断 |
| 可能解决的问题 | 结合区别特征，而非只复述效果目标 |
| 技术效果证据 | 记录、实施例或可信技术推理；注明类别 |
| 对申请的影响 | 需限缩、补实施细节、拆分候选或待代理师确认 |

## 4. 分开讨论新颖性与创造性

- **新颖性初筛**：逐项确认单一对比文件是否公开每个必要特征及其关系。把“检索未命中”表述为本次检索范围内未找到，不写成绝对新颖。
- **创造性分析**：围绕最接近的现有技术，列出区别特征、由区别特征实际解决的技术问题、是否存在结合/替换启示，以及技术效果是否有依据。按当前有效的审查指南核对适用标准。
- **实用性、客体、充分公开、清楚性和支持性**：分别列风险和证据，不用“有创新”一句话覆盖全部判断。
- **申请日前公开风险**：论文、预印本、网站、展会、销售、代码仓库和演示均可能影响时点分析。把公开证据和日期保存，并及时请专业人员判断宽限期或其他规则是否适用。
- **专利布局**：可以提出一个主申请和若干备选/分案候选，但每个分件都要有独立的技术依据、统一性分析和原始披露支持。不得为了数量把一个发明拆成多个申请。

## 5. 输出与限制

输出包括检索式、已核实文献列表、逐特征对比、检索限制、候选权利要求范围和待确认问题。未访问的数据库、被限流的查询、无法确认的文献要明确披露。不要编造专利号、公开日、申请人、文献内容或链接。

本分析不判断侵权、不构成 FTO 意见，也不保证授权。涉及具体法律标准时读取 references/06-authoritative-sources.md 并核验现行官方原文。
