# 权威来源与规则更新

## 核验原则

涉及专利可授权主题、申请文件、申请日/优先权、修改、审查意见、复审、年费、费用、期限或电子系统操作时，先检索当前官方材料。引用页面标题、发布机构、发布日期/生效日、访问日期和相关段落。发现旧版本时明确指出差异，不静默沿用。

优先级：

1. 国家知识产权局官网现行法律法规、部门规章、通知、系统帮助和办理指南。
2. 全国人大、国务院等发布的法律、行政法规原文。
3. WIPO 官方条约与办理指南，用于 PCT/海牙等国际程序。
4. 其他公开数据库和专业文章仅用于检索线索或解释，不覆盖官方原文。

检索到的摘要、搜索片段或第三方转载不足以支撑期限、费用或法律结论；打开并核对原始页面。若官方来源不可访问，写明未能核实，不以推测替代。
