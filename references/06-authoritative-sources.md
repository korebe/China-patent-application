# 6. 核对现行官方规则

专利法律、审查、费用、期限和电子系统会变化。回答这类问题前，先打开当前官方来源，再写结论。

## 来源顺序

1. 国家知识产权局官网的法律法规、部门规章、通知和办理指南
2. 全国人大、国务院发布的法律和行政法规
3. WIPO 官方材料：仅用于 PCT、海牙等国际程序
4. 其他网站：只用于寻找线索，不能替代官方原文

不要只引用搜索摘要或转载。核对原文、发布机构、发布日期和生效日期。无法打开官方来源时，说明尚未核实。

## 常用官方入口

- [国知局法律法规栏目](https://www.cnipa.gov.cn/col/col59/index.html)：从栏目中打开现行《专利法》
