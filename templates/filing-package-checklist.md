# 申请提交前检查清单

这是准备工作清单。当前文件格式和附件要求，以国知局系统当时的要求为准。

## 申请文件
- [ ] 已确认专利类型和申请策略
- [ ] 已准备权利要求书
- [ ] 已准备说明书或外观设计简要说明
- [ ] 已准备摘要
- [ ] 已准备所需附图/视图
- [ ] 名称、术语、图号、参数和引用关系一致
- [ ] 每项权利要求都有说明书依据
- [ ] 未确认的技术事实已标出
- [ ] 正式文件不含内部备注和不相关个人信息

## 请求书信息
- [ ] 申请人信息由本人/单位核实
- [ ] 发明人/设计人及顺序由本人核实
- [ ] 联系人、地址和代理信息已核对
- [ ] 优先权、分案或同日申请事项已核对
- [ ] 费用减缴资格和随案附件已核对

## 递交后
- [ ] 申请人/代理师已批准最终版本
- [ ] 已保存系统回执和申请号
- [ ] 已归档实际递交的文件版本
- [ ] 已创建通知、期限和缴费台账
