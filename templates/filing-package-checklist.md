# 申请文件与提交准备清单

本清单是工作底稿。当前案型的具体表式、文件格式和随案要求，应从国家知识产权局官方系统核对。

## 技术与文件
- [ ] 技术交底材料和来源台账归档
- [ ] 发明/实用新型/外观设计类型和申请策略已确认
- [ ] 权利要求书
- [ ] 说明书或外观设计简要说明
- [ ] 说明书摘要
- [ ] 说明书附图/视图及摘要附图（按案型适用）
- [ ] 名称、术语、附图标记、数据和公式在各文件中一致
- [ ] 每项权利要求均有说明书及来源材料支持
- [ ] 未确认事实没有被写成已实现事实
- [ ] 正式文件不含内部分析、提示词或无关个人信息

## 请求信息与程序
- [ ] 申请人/发明人或设计人信息由本人/组织核实
- [ ] 代理委托、联系人和签章事项由申请人/代理师确认
- [ ] 优先权、分案、同日申请及保密审查问题已核对
- [ ] 费用减缴资格和应缴项目已核实
- [ ] 申请文件清单与官方系统当前要求一致
- [ ] 申请人/代理师批准最终递交版本
- [ ] 递交后保存官方回执、申请号和提交文件版本
- [ ] 按官方系统和通知维护后续期限、缴费和案卷
